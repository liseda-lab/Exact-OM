# Prospective DEV evaluation with fallible judgments

The user approved moving forward with “ok perfect lets do that.” after the
proposal to measure evaluator disagreement, retain uncertain comparisons, and
compare all six existing models under one frozen policy. This is a prospective
amendment, not a reassessment of the previous qualification panels. Their failed
results, source versions, costs and unsuccessful repair histories remain intact.

SF-002, SF-010/011, SF-014/016 and SF-029 distinguish fallible proxy judgments,
ordinal information, unavailable cardinal scores and complete reporting. The
former requirement that every diagnostic be stable before any DEV evaluation
is superseded. A successful request is not proof of semantic truth; conversely,
one inconsistent judgment does not invalidate the complete experiment cohort.

## Frozen request and aggregation rules

There are 111 paid requests: 73 unary assessments and 38 independent direct pair
presentations. Repeat unary assessments on the six audited slots; direct pairs
use both orders there. First orientation alternates across hash-sorted matched
groups, identically for both arms. Identical complete request contexts are reused
within a repetition only. Reuse is not an independent agreement observation.
Direct comparisons never see the separately produced numerical scores.

Retain the three equally weighted criteria, anchors 0/.25/.5/.75/1, 0.05 tie
tolerance and 0.25 criterion repeat-range threshold. Require valid model/route,
schema, citations, native ownership, exact case/plan/protocol dependencies and
durable HTTP provenance. A full retention rating contradicting a supplied missing
intended commitment is invalid; identical current theories cannot have a strict
preference. Invalid observations remain in receipts and denominators.

An ordinal comparison is admissible when every scheduled direct preference,
canonicalized for order, agrees with each complete unary-derived preference and
the median-derived preference. Equal/disagreeing votes abstain; no winner is
silently flipped. Every required unary criterion must be available. Absolute
score variation can leave ordinal information usable when all rankings agree.
The raw direct votes remain separately reported even when admission fails.

Cardinal labels additionally require each criterion's repeat range to be at most
0.25. Aggregate by criterion median and fixed equal weights. Any required unknown,
missing/invalid observation, excess range or preference conflict masks the
affected numeric comparison. Never renormalize over known criteria. Keep raw
anchors, reasons, citations, criterion medians/ranges and descriptive totals.
These DEV observations are not admitted as new TRAIN supervision.

Report every model's logical and semantic denominator, direct and admitted
win/tie/abstain counts, per-family and per-seed paired differences, and unique
parent counts. Compute a deterministic 2,000-draw parent bootstrap (seed 4713)
for descriptive intervals when at least two evaluable parents exist. Repetitions
and multiple models never become independent parents. Report full-denominator
sensitivity with every unavailable arm difference ranging over [-1,1]. Only a
direction supported by both the interval and sensitivity bounds is called a
directional DEV proxy difference; otherwise report inconclusive. Neither outcome
establishes real-world semantic quality or calibrated confidence.
