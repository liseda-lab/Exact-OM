# Controlled conflict-incidence diagnostic

The overlap branch projects the lexicographically first declared fresh overlap
parent to a small controlled motif. It inherits that parent's group and split;
projection is explicit and does not preserve the original ontology's complexity.
All variants are one diagnostic ancestry group, with no held-out or population
claim. Selection uses the frozen input schedule, without reading study outcomes.

The corrupted motif has five classes S, X, Y, A, B; fixed disjointness of S
with A and B; and four editable inclusions. The nonshared condition is
`S ⊑ X`, `X ⊑ A`, `S ⊑ Y`, `Y ⊑ B`. The shared condition replaces only
the fourth inclusion with `X ⊑ B`. Its two minimal supports share edge zero;
the nonshared condition's two supports have no editable edge in common.
All objects have identical authored status, observed scores and edit-cost rules.
The intended repair deletes edges one and three, preserving the same two
prefix entailments. Each condition also has a coherent control that observes
the intended theory. Coherent controls retain ancestry and denominator, with
two nonempty observed mappings after omitting the two absent mappings. They
are coherence checks; their mapping counts are not matched to corrupted cases.
The two corrupted incidence conditions both retain four mapping objects.

Before execution, a versioned design amendment corrects the initially prepared
coherent inputs, which represented absent mappings as empty original relations
unsupported by endpoint retrieval. The original unsubmitted preparation stays
intact. The correction follows the static input contract; no witness or
evaluation outcome selects it. Budgets, models, probes and split ancestry stay
unchanged, and the amendment is bound to the revised frozen schedule.

Before inference, a native HermiT witness worker checks all sixteen keep/delete
subsets of each corrupted motif, identifies its exact minimal infeasible
supports, and verifies the coherent controls. Each case has a 300-second wall,
600-second CPU, 8192-MiB bound. Incomplete or mismatching evidence makes that
case explicitly unavailable for all nine arms. It never removes scheduled rows
or supplies an unqualified logical label. Witnesses stay outside model inputs.

The evaluation freezes the same six pilot checkpoints and symbolic retention,
uniform and deletion controls as the earlier robustness branch: four cases and
36 arm rows. Generation has the original 60-second allowance within each
300-second case limit. Three operational slices run twelve rows each. Saved
receipts bind source, runtime, schedule and proofs; unfinished rows require
ownership and budget reconciliation before a replacement. A final report
checks every row against the frozen denominator and retains unknowns and costs.

Structural fingerprints union all variants, the original ancestry, historical
exposures and every declared corpus split, including transitive aliases. This
audit can further restrict interpretation; it cannot promote the diagnostic to
new independent test parents. Existing symbolic-control limitations and G0–G2
restrictions remain. No additional model training or checkpoint selection is
performed, and no API expenditure is authorized.

The terminal receipt audit uses `tools.repair.overlap_audit` in a separately
frozen, charged worker. It verifies the original and replacement step/nonces,
source exports, runtimes, output manifests, checkpoints, native witness subset
coverage, row payloads, paired availability and settled attempt charges. It
preserves the original report and all failed attempts. Its process-status and
scientific-status counts remain separate: a completed process can contain a
timeout or an unavailable model schema. This worker makes no new native calls
and repeats no scientific rows. Its completion closes only the registered
overlap diagnostic stage; the remaining expanded program stays pending.
