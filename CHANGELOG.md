# Changelog

## 2.0.0

- Portable native evidence, gated Elephant decisions, local ranking and calibrated global acceptance stages.
- Separate full and partial operating policies; explicit imports for frozen final models and the retained NCIT–DOID full head.
- Source-boundary native checkpoints, durable decision reuse, fold-safe fitting and artifact integrity checks.
- Java-free ontology input stack, configurable class/property/individual matching, track retrieval and explanation export.
- Correct successful CLI exit statuses and bundled offline examples/profiles.
- Standard wheel/sdist packaging with direct runtime dependencies and installed-command checks.
- Exact Explain local explorer with candidate comparison, hierarchy browsing, evidence graphs, decision traces, scores and portable bundle import/export.
- Built frontend included in wheel/sdist; optional `viz` server dependencies and local installation guide.
- Research orchestration, agent specifications, ontology repair, study/admin apps and private deployments excluded from this release.
